 # ⏰ CHRONO — Digital Clock & Alarm

A futuristic digital clock and alarm web application built using HTML, CSS, and JavaScript.

---

## 🚀 Features

- 🕒 Real-time digital clock
- ⏰ Multiple alarm support
- 💤 Snooze functionality
- 🔔 Alarm sound system
- 🌙 Dark / Light mode
- 🔄 12-hour & 24-hour format
- 💾 Local storage support
- 📱 Fully responsive UI
- ✨ Modern futuristic design

## ⚙️ How It Works

1. Displays real-time local clock
2. User can:
   - Add alarms
   - Toggle alarms ON/OFF
   - Snooze alarms
   - Delete alarms
3. Settings are saved in localStorage
4. Alarm rings using Web Audio API
